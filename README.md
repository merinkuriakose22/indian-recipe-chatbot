Indian Recipe Assistant AI

An AI-powered chatbot for Indian cooking guidance built using Gradio, Groq API, and Llama 3.3 70B.

Features
Indian recipe recommendations
Cooking guidance and techniques
Ingredient suggestions and substitutions
Interactive conversational chatbot
Fast inference using Groq-powered LLMs
Simple Gradio web interface


Tech Stack
Python
Gradio
Groq API
Llama 3.3 70B Versatile Model
